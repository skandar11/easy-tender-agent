# Ответить — из базы

**Когда:** владелец спрашивает о своём — поставщиках, заказчиках, прошлых лотах,
договорённостях, своём бизнесе.

1. **Сначала `baza/HOME.md`** — найди страницы по теме; потом открой их.
2. **Каждый факт — со страницей,** откуда он: «по [[stranicy/…]]». В базе нет — так и
   скажи, не придумывай.
3. Вопрос про тендеры, портал, правила госзакупок — не из базы: **EASY TENDER**
   (`easytender_method`, затем его инструменты).
4. Ответ ценный и пригодится снова → запиши его страницей сам (операция «записать»), не спрашивая.
