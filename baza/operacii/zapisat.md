# Записать — новое в базу

**Когда:** владелец сказал что-то, что меняет знания (решение, факт о поставщике,
заказчике, своём бизнесе, итог лота); прислал файл; файл лежит в `vhodyashchie/`;
конец сессии. Фразы: «запиши», «запомни», «разбери входящие».

1. **Прочитай источник целиком.** Файл из `vhodyashchie/` — весь, не первые строки.
2. **Обсуди с владельцем, что важно** — что меняет, что выделить. Пропускается, если
   источник — его же слова только что.
3. **Разложи:** дело → `plan.md`; знание → шаг 4; мусор → `arhiv/` и строка в `arhiv/INDEX.md`.
4. **Страница:** подходящая есть — дополни; нет — новая `baza/stranicy/<имя-латиницей>.md`:
   заголовок, суть, откуда (дата, «со слов владельца» или имя файла), ссылки `[[…]]` на соседей.
   Слова владельца — цитатой, если это решение.
5. **Строка в `baza/HOME.md`** для каждой новой страницы.
6. **Строка в `baza/log.md`:** `## [дата] записать | <что>` — источник → тронутые страницы.
7. Файл из `vhodyashchie/` разобран → в `arhiv/` (строка в `arhiv/INDEX.md`).

Тендерные данные (лоты, документы, победители) в базу не переписываются: они на
сервере EASY TENDER. В базу — то, что владелец решил по ним: «по лоту N — идём / не идём, потому что…».
