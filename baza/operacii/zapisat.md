# Записать — новое в базу

**Когда:** владелец сказал что-то, что меняет знания (решение, факт о поставщике,
заказчике, своём бизнесе, итог лота); прислал файл; файл лежит в `vhodyashchie/`;
конец разговора. Не жди фраз «запиши» или «запомни» — записывай сам, сразу, молча.

1. **Прочитай источник целиком.** Файл из `vhodyashchie/` — весь, не первые строки.
2. **Реши сам, что важно,** и не спрашивай. Владельцу потом — одна строка, что взял
   («Записал прайс поставщика X: 12 позиций»). Спроси одно, только если файл непонятно чей или о чём.
3. **Разложи:** дело → `plan.md` или `backlog.md`; сырая мысль → `idei.md`; мусор → `arhiv/`
   и строка в `arhiv/INDEX.md`; всё, что несёт знание, → шаги 4–6.
4. **Страница источника** — `baza/istochniki/ГГГГ-ММ-ДД-<о-чём>.md` ([[../istochniki]]): что это,
   где лежит файл, суть, **что изменил**. Слово владельца в чате — не источник, а решение:
   `baza/resheniya/` ([[../resheniya]]).
5. **Тронутые страницы:** подходящая есть — дополни; нет — новая: знание → `baza/stranicy/`,
   человек или организация → `lyudi/` ([[../lyudi]]). По правилам [[../kak-pisat]].
   Обычно один источник трогает несколько страниц — пройди все.
6. **Строка в `baza/HOME.md`** для каждой новой страницы.
7. **Строка в `baza/log.md`:** `## [дата] записать | <что>` — источник → тронутые страницы.
8. Файл из `vhodyashchie/` разобран → в `arhiv/` (строка в `arhiv/INDEX.md`).

Тендерные данные (лоты, документы, победители) в базу не переписываются: они на
сервере EASY TENDER. В базу — то, что владелец решил по ним: «по лоту N — идём / не идём, потому что…».
