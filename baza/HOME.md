# База — каталог

Каждая страница базы — одна строка здесь: ссылка и что на ней. Операция
«записать» добавляет строку, когда страница рождается; «ответить» читает этот
файл первым; страница без строки — потерянная, её находит «проверить».
Журнал изменений — [[log]].
