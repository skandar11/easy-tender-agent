# EASY TENDER — ваш агент для госзакупок

Папка-агент: ваш помощник для тендеров Казахстана. Он помнит ваши дела в этой папке,
а метод Алии Умаровой и данные портала госзакупок берёт с сервера EASY TENDER по
вашему ключу. Ставить Python, токены портала и программы не нужно.

## Что нужно

- **Claude** с подпиской Pro или Max — приложение Claude Desktop или Claude Code.
- **Ключ доступа** `ETK-XXXX-XXXX` — приходит после оплаты в WhatsApp.
  Тариф «С обучением» — два ключа: агента и курса.

## Как начать

1. Скачайте папку: зелёная кнопка **Code → Download ZIP** и распакуйте ближе к корню
   диска, например `C:\tender\`. Или:
   `git clone https://github.com/skandar11/easy-tender-agent.git`
2. **Claude Code:** откройте папку и напишите `/mcp` → `easytender` → **Authenticate** —
   откроется страница «Введите ключ доступа», введите ключ агента. Для курса так же — `kurs`.
   **Claude Desktop (Cowork):** Настройки → Коннекторы → Add custom connector →
   `https://mcp.easytender.kz/mcp`; для курса — второй коннектор `https://kurs.easytender.kz/mcp`.
   Затем выберите эту папку рабочей.

   Ключ вводите вы сами — агент открыть эту страницу за вас не может.
   Выберите **один** способ — `/mcp` или коннектор в настройках: если
   сделать оба, сервер подключится дважды.
3. Первое сообщение: **«Привет, давай познакомимся»** — агент спросит про ваш бизнес и
   запомнит. Дальше: «найди тендеры на …», «разбери лот …», «начнём курс».
