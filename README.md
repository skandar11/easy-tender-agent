# EASY TENDER — ваш агент для госзакупок

Папка-агент: ваш помощник для тендеров Казахстана. Он помнит ваши дела в этой папке,
а метод Алии Умаровой и данные портала госзакупок берёт с сервера EASY TENDER по
вашему ключу. Ставить Python, токены портала и программы не нужно.

## Что нужно

- **Claude** с подпиской Pro или Max — приложение Claude Desktop.
- **Ключ доступа** `ETK-XXXX-XXXX` — приходит после оплаты в WhatsApp.
  Тариф «С обучением» — два ключа: агента и курса.

## Как начать

1. Скачайте папку: зелёная кнопка **Code → Download ZIP** и распакуйте ближе к корню
   диска, например `C:\tender\`. Внутри архива — папка `easy-tender-agent-main`: рабочая
   папка — та, где лежит файл `CLAUDE.md`. Или:
   `git clone https://github.com/skandar11/easy-tender-agent.git`
2. Подключите EASY TENDER **коннектором** в Claude: **Настройки → Коннекторы → Add custom connector**
   (добавить свой коннектор):
   - название `EASY TENDER`, адрес `https://mcp.easytender.kz/mcp` → **Connect** — откроется страница
     «Введите ключ доступа», введите ключ агента;
   - тариф «С обучением» — второй коннектор: `EASY TENDER Курс`, адрес `https://kurs.easytender.kz/mcp`,
     ключ курса.

   Ключ вводите вы сами — агент открыть эту страницу за вас не может. Коннектор добавляется
   один раз и работает во всех ваших чатах Claude.
3. Откройте эту папку (ту, где `CLAUDE.md`) рабочей в Claude Desktop (Cowork или Code) — так агент помнит ваши дела.
4. Напишите что угодно, например **«Привет»**. Агент сам проверит подключение, задаст три
   вопроса о вашем бизнесе, запомнит ответы и сразу покажет первые подходящие тендеры.
   Дальше просто говорите: «найди тендеры», «разбери лот …», «начнём курс».
   Когда Claude впервые спросит разрешение на инструмент EASY TENDER, выберите
   **«Разрешить всегда»** (Always allow). Тогда он больше не будет спрашивать.

## Что где

- `CLAUDE.md` — правила агента (читает он, не вы).
- `baza/` — память агента о вас: бизнес, решения, всё, что вы рассказали. Обычные текстовые файлы — ваши.
- `lyudi/` — поставщики, заказчики, контакты; появится с первой карточкой.
- `plan.md` · `backlog.md` · `idei.md` — что делаем сейчас, что ждёт, ваши идеи.
- `vhodyashchie/` — кидайте сюда документы, агент разберёт.
- `arhiv/` — сюда уходит ненужное: агент ничего не удаляет.
- `baza/kak-govorit.md` — как агент с вами говорит; дописывайте свои правила внизу.
